التكرار: for و while و do-while

افتح على يوتيوب
Print 1 to 100
void main() {
  for (var i = 1; i <= 100; i++) {
    print(i);
  }
}
The 3 parts of for (prints 0 to 4)
void main() {
  for (var i = 0; i < 5; i++) {
    print(i);
  }
}
Sum 1 to 10
void main() {
  var sum = 0;
  for (var i = 1; i <= 10; i++) {
    sum = sum + i;
  }
  print(sum);
}
Factorial of 5
void main() {
  var fact = 1;
  for (var i = 1; i <= 5; i++) {
    fact = fact * i;
  }
  print(fact);
}
Even numbers (two ways)
void main() {
  // 1) step by 2
  for (var i = 2; i <= 100; i += 2) {
    print(i);
  }

  // 2) check with %
  for (var i = 1; i <= 100; i++) {
    if (i % 2 == 0) {
      print(i);
    }
  }
}
Prime check with break and a flag
void main() {
  var n = 7;
  var isPrime = true;
  if (n <= 1) {
    isPrime = false;
  } else {
    for (var i = 2; i < n; i++) {
      if (n % i == 0) {
        isPrime = false;
        break;
      }
    }
  }
  print('$n prime? $isPrime');
}
while (countdown)
void main() {
  var i = 3;
  while (i > 0) {
    print(i);
    i--;
  }
}
do-while
void main() {
  var i = 0;
  do {
    print(i);
    i++;
  } while (i < 3);
}
break and continue
void main() {
  for (var i = 1; i <= 10; i++) {
    if (i == 4) break;
    print(i);
  }

  for (var i = 1; i <= 5; i++) {
    if (i == 3) continue;
    print(i);
  }
}
Nested loops
void main() {
  for (var r = 1; r <= 3; r++) {
    for (var c = 1; c <= 3; c++) {
      print(r * c);
    }
  }
}
  • الـ loop بيكرر كود من غير ما تكتبه بإيدك. بدل مية سطر print بتكتب تلاتة.
  • قبل أي loop اسأل نفسك تلات أسئلة: أبدأ من كام؟ أقف إمتى؟ وبزيد كام في كل لفة؟
  • الـ for فيها تلات أجزاء: بداية، شرط، زيادة. البداية بتتنفذ مرة واحدة، وبعدين كل لفة: شرط، تنفيذ، زيادة.
  • تتبّع الـ loop لفة لفة (i، الشرط، الكود، الزيادة) عشان تلاقي أي غلطة.
  • i < 5 يدي 5 لفات، و i <= 5 يدي 6 لفات.
  • متغير الجمع sum بنكتبه قبل الـ loop. أي متغير جوه الـ loop بيتعمل من جديد في كل لفة وبيختفي في آخرها.
  • while لما مش عارف عدد اللفات. لازم تغيّر قيمة جوه الـ loop وإلا هتبقى infinite loop، وتوقفها بـ Ctrl + C.
  • do-while بتنفذ الكود مرة على الأقل وبعدين تتشيك على الشرط.
  • break بتقفل الـ loop كلها، و continue بتتخطى لفة واحدة.
  • الأرقام الأولية: isPrime بـ true، ولو لقيت رقم بيقسم تخليها false وتكتب break. وخد بالك من 0 و 1: مش أوليين.
