# Mobile App A to Z, notes and code

Source of https://mobile-app-a-to-z.pages.dev (Cloudflare Pages).

- `lessons.js`: lesson notes, code and tasks (data-driven)
- `build.mjs`: builds the static site (`node build.mjs / outdir`)
- `app.js`, `style.css`, `fcm-sw.js`: front end
- `functions/`: Pages Functions (grading, watch tracking, chatbot, problem reports, push). Keys and secrets are Cloudflare secrets, never in this repo.
